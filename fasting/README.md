# 轻断食计时

iPhone 主屏幕上用的轻断食 Web App（PWA）。不需要服务器、账号或 App Store，数据只保存在这台 iPhone 上。

## 怎么用

- **每次开始吃饭时按一下“开始吃饭”**，不用按“吃完”
- 当天最后一次按下的那顿，会被自动当作最后一餐，从吃完开始算禁食（每顿饭按 30 分钟算，可以在设置里改）
- 第二天第一次按“开始吃饭”，前一晚的禁食会自动记下，并判断有没有达标
- 忘了按可以补记，按错了可以在“吃饭记录”里点一下删除
- 支持 14:10、16:8、18:6 三种方案，以及连续打卡和黑咖啡截止时间（睡前 8 小时）
- 凌晨 4 点前吃的东西算前一天

## 装到 iPhone 主屏幕

1. 用 **Safari** 打开这个 App 的网址
2. 点 **分享**（方框加箭头）→ **添加到主屏幕**
3. 以后只从主屏幕的图标打开

## 备份

设置 → **复制备份**，把复制的文字粘贴到备忘录保存。换手机时用 **粘贴恢复** 导回来。

## 更新代码

1. 修改文件
2. 把 `sw.js` 里 `CACHE` 的版本号加一（比如 `v2.0.1`）
3. 提交并推送。GitHub Pages 大约一分钟后更新
4. 在 iPhone 上关掉 App 再打开，必要时重复一次

## 文件

| 文件 | 用途 |
|---|---|
| `index.html` | 整个 App：界面、样式和逻辑 |
| `sw.js` | 离线可用（Service Worker） |
| `manifest.webmanifest`、`icons/` | 主屏幕上的名字和图标 |
